# Harvester

Скрипт для проверки прокси-нод: TCP-пинг -> замер скорости через xray + Cloudflare trace -> фильтрация по гео (без RU/XK/BY/KP/SY/IR/CU/VE).

## Как использовать

1. Положи ноды в core/nodes.txt
2. Запусти: python harvester.py
3. Результат в assets/non_ru.txt - чистые зарубежные ноды с скоростью >= 48 Мбит/с

## GitHub Actions

Для автозапуска каждые 30 минут -- залей репу на GitHub и включи Actions. Xray скачивается автоматически, файлы assets/*.txt пушатся обратно после каждого запуска.
